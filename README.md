# myPortfolio

Personal portfolio for **Hamza Kamkoum** &mdash; computer engineering grad from TEK-UP (Tunisia), focused on backend, platform engineering, automation and agentic AI.

Live site: https://kamkoum04.github.io/myPortfolio/

## Stack
- Static HTML + Tailwind CSS (via CDN)
- Poppins (Google Fonts)
- Plain JS for scroll reveals & nav highlight

## Run locally
Just open `index.html` in a browser, or:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```
